# 知课 AI · 基于课件的教学一体化平台

把课件变成知识导图、练习、批改与学情的 AI 教学闭环。

面向高校课堂的「课件 → 知识导图 → 练习 → 批改 → 学情」闭环演示，纯前端静态实现，无需后端与安装依赖。

## 核心功能

### 学生端
- 知识导图：按章节 / 小节 / 知识点逐层展开，查看公式、参数含义、示例与课件页码。
- 多课程学习：一个行政班对应多门课程，首页课程卡片、顶栏下拉、导图上方切换条均可切换。
- 课堂与作业：作业统一展示（不区分来源），未完成在上、已完成自动排到下面，右侧直接查看批改与标准答案。
- 错题本：按科目汇总错题，勾选后重新做一遍，重做不覆盖原成绩，答对标记「已订正」；每题支持 AI 同知识点变式题，举一反三。
- AI 问答：接入真实大模型作答，回答标注课件页码、可溯源；提问汇总给教师用于讲评。
- 作答留痕：支持拍照上传、手写公式识别（转 LaTeX 逐步比对）。
- 扫码 / 班级号入班。

### 教师端
- 课件生成与交互式思维导图编辑。
- 备课与出题：教材例题、教材课后习题、AI 出题、自拟题，按需选择性发放。
- 作业与试卷发布、批改复核、AI 提问汇总、匿名问答。
- 学情看板：知识点掌握度雷达图（覆盖全部知识点，未测项灰色标注）、共性问题、错题汇总（按知识点聚合，标注「建议下节课先提」）。
- 行政班管理：创建班级、生成班级号与二维码；课程可开设到多个班级，支持跨专业。

## 数据模型

`专业 → 行政班 → 学生`，课程独立于班级：

- 行政班：一个班号对应一个班，学生只属于一个行政班。
- 课程：由教师创建，通过 `classIds` 开设到多个行政班。
- 选课关系：学生入班后自动获得本班全部课程。
- 教师端按「课程 → 班级」两级切换，学情与批改数据按课程 + 班级隔离。

### 大模型接口（OpenAI 兼容协议，前端浏览器直连）
AI 问答、AI 出题、错题变式、简答题批改与手写公式识别调用真实大模型，默认使用 Agnes AI：

| 项目 | 内容 |
| --- | --- |
| 默认提供商 | Agnes AI |
| 模型名称 | `agnes-3.0-flash` |
| Base URL | `https://api.agnes-ai.cn/v1` |
| 接口协议 | OpenAI Chat Completions 兼容协议 |

顶栏「模型」按钮可切换其他服务商（以下均为 OpenAI 兼容接口），模型不限：
- DeepSeek：`deepseek-chat`（`https://api.deepseek.com/v1`）
- 硅基流动：`Qwen/Qwen2.5-7B-Instruct`（`https://api.siliconflow.cn/v1`）
- OpenRouter：`openai/gpt-4o-mini`（`https://openrouter.ai/api/v1`）
- 通义千问：`qwen-plus`（`https://dashscope.aliyuncs.com/compatible-mode/v1`）
- 自定义：任意 OpenAI 兼容 Base URL + 模型名

> API Key 仅保存在浏览器本机 `localStorage`（独立键 `zhike_llm_config`），不写入代码、不上传仓库。仓库中不含任何密钥。

## 本地运行

方式一：直接打开 `dist/知课AI-单文件版.html`。

方式二：在项目根目录启动静态服务器：

```bash
python -m http.server 5173
```

然后访问 <http://127.0.0.1:5173/>。

## 重新生成单文件版

修改源码后，在项目根目录执行：

```bash
python tools/build_dist.py
```

脚本会把 `index.html`、`styles.css`、`js/*.js` 与 `slides/` 中的幻灯片图片内联为 `dist/知课AI-单文件版.html`，可离线独立打开。

## 说明

- 演示数据保存在浏览器 `localStorage`，右上角「重置演示」可恢复初始数据。
- AI 问答由真实大模型生成，教材页码锚定（原文引用卡片、跳转按钮）由前端知识点匹配层提供，回答被约束在匹配到的教材片段范围内。
- 未配置 API Key 时自动回退到本地演示回答，保证演示不中断。
- 无构建依赖，修改源码后在浏览器刷新即可生效。
