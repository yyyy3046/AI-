二、开发环境与方式

开发平台TRAE（AI 辅助编程 / Vibe Coding，本次比赛统一平台）
技术栈原生 HTML / CSS / JavaScript，纯前端静态实现，无后端、无构建依赖
版本管理Git + GitHub，仓库 yyyy3046/AI-（main 分支）
大模型默认 Agnes agnes-3.0-flash（OpenAI 兼容接口），可切换 DeepSeek / 硅基流动 / OpenRouter / 通义千问
验证方式本地静态服务器（python -m http.server）+ 浏览器端到端实测 + 控制台无报错 + 线上部署复核
交付形态在线演示 + dist/知课AI-单文件版.html（离线可双击运行）

五、开发过程中的验证

  • 功能实测：每轮改动后在浏览器端走完整链路（登录 → 导图 → 课件 → 作答 → 批改 → 学情），并检查控制台无报错。
  • 数据完整性：用控制台脚本核对知识点总数、按章节/小节分布、页码区间与引用断裂，确保无悬空引用。
  • AI 匹配回归：「什么是导数」「微分的几何意义」「高阶导数」「极限的四则运算法则」等提问逐一验证命中页码正确。
  • 降级保障：未配置 Key、模型超时或视觉识别失败时自动回退本地评分/本地回答，保证演示不中断。
