# 知课 AI 高保真可点击 Demo 实施计划

## Context

用户希望在黑客松开发前，先看到“知课 AI”教育网站的实际效果。第一版明确采用高保真可点击 Demo：模拟 PPT 解析和 AI 结果，但页面、操作和双角色数据联动必须真实可用，并符合飞书选手手册对“可运行、可现场演示原型”的要求。

工作区当前为空，没有既有代码。环境中没有 Node.js/npm，已确认 Python 3.14.6 可用，因此采用零依赖静态 Web 应用，避免安装运行环境，同时保留后续迁移到前后端和真实 AI 接口的清晰边界。

## 推荐方案

使用原生 HTML、CSS、JavaScript 构建单页应用，通过 Hash 路由切换页面、`localStorage` 保存演示状态。无需 npm 或构建步骤；使用 Python 启动本地预览服务。

示例课程固定为《人工智能基础》，示例课件为“机器学习基础.pptx”。内容包含 1 个章节、3 个小节、6 个知识点、3 道单选题和 1 道简答题。首次进入即能看到完整示例，也可重新播放模拟上传和 AI 生成过程。

## 页面与核心交互

### 1. 登录与应用框架

- 学生、教师双入口，一键使用演示账号登录。
- 教师默认进入课件工坊，学生默认进入知识导图。
- 桌面端为侧边栏与顶栏，移动端折叠导航；顶栏支持角色切换和重置演示。
- 页面明确标注“模拟 AI / 演示数据”，不伪装真实模型调用。

### 2. 教师课件工坊

- 支持选择 PPT 文件或点击“使用示例课件”，仅读取文件名，模拟上传、解析、导图构建和出题进度。
- 生成三级思维导图：章节→小节→知识点；支持展开、收起和选中。
- 点击知识点显示公式、参数含义、示例、PPT 来源页码与原文；示例公式包括线性回归、Sigmoid、K-Means 和 MSE。
- AI 生成 4 道草稿题，教师可编辑题干、选项、答案和分值，并发布为课堂问答或课后作业。

### 3. 学生学习与批改

- 学生与教师共用同一份思维导图和题目数据。
- 学生完成课堂问答/作业，支持答题卡、答案保存和提交。
- AI 答疑提供“一点提示→进一步提示→完整解析”三级反馈；输入追问时返回当前题目的模板化解释。
- 单选题真实自动判分，简答题模拟 AI 评分、评语和扣分依据。
- 错题诊断展示错因、关联知识点、复习建议和相似题，并可跳回对应导图节点。

### 4. 私信与匿名问答

- 学生可私信教师，默认仅双方可见，可关联题目或知识点。
- 学生发送时可选择“匿名公开到课程问答广场”；私有问题不能出现在公共视图。
- 公共卡片仅生成“匿名同学”展示信息，不包含姓名、头像或学号，而非仅用 CSS 隐去。
- 教师在同一消息上回复后，学生私信和公开问答同步显示答案。
- 公共范围按本课程师生设计，不做互联网公开。

### 5. 教师复核与学情看板

- 教师可修改简答题分数、评语并完成复核，学生端同步更新成绩与状态。
- 看板从实际提交记录计算提交率、平均分、正确率、知识点掌握和共性错题，不另写一套静态结果。
- 使用轻量 CSS/SVG 图表，不引入图表或图谱依赖。

## 关键文件

- `e:\大模型\trae文件开发\index.html`：应用容器、页面入口与脚本引用。
- `e:\大模型\trae文件开发\styles.css`：完整视觉系统、页面布局、导图、看板、抽屉和响应式样式。
- `e:\大模型\trae文件开发\app.js`：领域类型注释、演示种子数据、状态管理、Hash 路由、页面渲染、模拟 AI 与全部交互。

为保持首版简单，不拆分大量组件文件；在 `app.js` 内按“数据 / 状态 / 模拟服务 / 视图 / 事件”分区。AI 调用集中为独立函数，后续可用真实 `/api/ai/*` 请求替换，页面不保存任何模型密钥。

## 实施步骤

1. 创建静态应用骨架、视觉变量、登录页、角色应用壳和路由。
2. 加入完整示例数据、持久化、角色切换和可重复重置机制。
3. 实现模拟课件上传、AI 生成进度、交互导图、知识详情和题目编辑发布。
4. 实现学生作答、三级 AI 答疑、自动判分、模拟主观题评分与错题诊断。
5. 实现私信、匿名公开、教师回复、教师复核和双端同步。
6. 实现由提交数据驱动的学情看板，补齐空状态、加载状态、防重复提交与移动端适配。
7. 启动本地服务，按完整路演流程进行浏览器验收并修复问题。

## 验证

启动命令：

```powershell
python -m http.server 5173 --bind 0.0.0.0
```

预览地址：`http://localhost:5173`。

端到端验证清单：

- 教师一键登录，重播示例课件生成，看到三级导图与 4 道可编辑题目。
- 点击“线性回归”等知识点，正确显示公式、参数、示例和 PPT 页码。
- 教师修改并发布题目，学生端出现相同内容与任务。
- 学生故意答错题目，完成三级 AI 答疑、提交、批改和错题诊断。
- 刷新后作答结果保留，重复提交受到限制。
- 私有提问不进入问答广场；匿名公开问题不泄露学生身份。
- 教师回复后，私信和公开问答同步；教师复核后，学生成绩同步。
- 学情指标随提交与复核结果变化，重置后恢复统一初始状态。
- 所有可见按钮均有行为，控制台无未处理异常。
- 1280×720 和 390×844 下均可完成登录、看图、作答、提问和查看结果。
