# 知课AI — 大模型判分 / 照片识别 / 限时 / 自主练习 — 产品需求文档

## Overview
- **Summary**：在现有纯前端教学平台中补齐四块能力——真实大模型参与主观题判分、照片手写识别参与判分、课堂问答限时倒计时自动交卷判分、学生端自主练习与真题库。
- **Purpose**：解决"学生端偏弱、作答只是普通选择题、AI 判分是本地假规则"的问题，让判分与练习具备真实 AI 能力与考试场景。
- **Target Users**：学生（李同学等）、教师（张老师等）。

## Goals
- 配置大模型后，主观题判分走真实模型；未配置时保持现有本地评分可用。
- 主观题附照片时，视觉模型识别手写内容并参与判分；无视觉模型时优雅降级。
- 课堂问答作答页显示倒计时，归零自动提交并判分。
- 学生端新增"自主练习"：可从内置真题库按知识点 / 难度抽题组卷，也可用大模型现场出题；作答后自动判分、看解析，并记录练习历史。

## Non-Goals
- 不做后端服务；不做账号体系改动；不做班级 / 权限改动。
- 不引入新的外部依赖库（纯原生 JS）。
- 真题为基于现有课件内容编制的代表性考试风格题，不保证与某校真实试卷逐字一致。
- 不改动教师端已有课件生成、导图编辑、批改复核等既有流程。

## Background & Context
- 纯前端，数据存 `localStorage`；`seed.version` 由 4 升到 5 会触发旧浏览器自动重建数据。
- 已有 `callLLM`（OpenAI 兼容 `/chat/completions`）、配置 UI（preset：agnes / deepseek / siliconflow / openrouter / dashscope）、`testLlmConnection`；已用于 AI 答疑 / AI 问答，但**判分仍用 `mockAi.gradeShortAnswer`**。
- 照片作答已支持（单选 / 简答都能附图，存 dataURL，最长边 1000px），但判分注释为"AI 暂不评阅图片内容"。
- 作业分 `mode: 'quiz'`（课堂问答）/ `'homework'`（课后作业）；quiz 有 `note: '课堂内 10 分钟完成'` 但无结构化 `duration`、无倒计时、无自动交卷。
- 脚本加载顺序：`data.js → store.js → actions.js → views-common.js → views-teacher.js → views-student.js → app.js`，全局函数无模块。
- `index.html` 静态资源当前 `v=56`，本轮需 bump；`dist/知课AI-单文件版.html` 需重建。
- 仓库：GitHub `main`，改完直接 commit + push；只提交 `index.html` / `styles.css` / `js/` / `dist/` / `README.md` / 访谈记录表 / 问卷二维码。
- 经验教训：多供应商视觉识别必须每家独立 adapter（endpoint / 鉴权 / payload 是否支持 `content` 数组与 `image_url`），禁止同一 OpenAI 风格 payload 硬套所有厂商。

## Functional Requirements
- **FR-1**：主观题判分在配置大模型后走真实模型，返回分数 + 评语 + 分步解析；未配置或失败时回退本地评分。
- **FR-2**：主观题附照片时，将图片发送给视觉模型识别手写内容，并结合题目 / 知识点 / 教材要点判分。
- **FR-3**：课堂问答（`mode === 'quiz'`）作答页显示倒计时（默认 10 分钟，可在作业数据中配置 `duration`），归零自动提交并判分。
- **FR-4**：学生端新增"自主练习"入口与页面，内置真题库可按课程 / 知识点 / 难度抽题组卷。
- **FR-5**：自主练习内可调用大模型现场出题（指定知识点 + 难度），生成的题可立即作答。
- **FR-6**：自主练习作答后自动判分（单选即时、简答本地 / 大模型），展示标准答案与解析，并写入练习历史。
- **FR-7**：AI 模型设置增加"视觉模型"配置项（可与文本模型相同或不同），含连接测试；未配置视觉模型时照片识别自动降级。
- **FR-8**：数据升级：`seed.version` 升至 5，旧浏览器自动重建；新增字段对旧数据做兼容兜底。

## Non-Functional Requirements
- **NFR-1 离线可用**：未配置任何 Key 时，所有功能仍可用（本地评分、内置题库、倒计时），不报错、不卡 UI。
- **NFR-2 性能**：照片压缩后单张 ≤ ~200KB；单次判分 / 出题请求超时 40s。
- **NFR-3 健壮性**：LLM 返回非 JSON / 网络失败 / 超时时，自动回退本地评分并提示，不丢已作答数据。
- **NFR-4 一致性**：AI 输出必须关联课件页码（沿用 `citePoint`）。
- **NFR-5 可追溯**：每次大模型判分 / 出题在结果处标注"由 AI 生成 / 仅供参考"。

## Constraints
- **Technical**：纯前端原生 JS，无构建；`localStorage` 上限 ~5MB，图片需压缩。
- **Business**：纯前端直连大模型，API Key 仅存本机 `localStorage`，不发送到任何自有服务器。
- **Dependencies**：视觉能力依赖用户配置支持视觉的模型（如 gpt-4o-mini、通义千问视觉版等）。

## Assumptions
- 用户可自行在"AI 模型设置"中填入支持视觉的模型的 Base URL / 模型名 / Key。
- 内置真题由本项目基于现有高数 / 大物课件知识点编制。

## Acceptance Criteria

### AC-1：主观题判分可走真实大模型
- **Type**：`rule`
- **Given**：学生已在 AI 模型设置中配置可用的文本模型（连接测试通过），并提交一道含主观题的作业
- **When**：系统对该主观题进行 AI 初评
- **Then**：调用真实大模型获取分数与评语，结果写入 `aiReviews`；教师复核页能看到该分数与评语
- **Pass Condition**：配置模型后提交主观题，`aiReviews` 中该题 `usedLLM === true`（或等价标记），分数来自模型返回
- **Evidence**：浏览器自测——配置 Key → 提交简答作业 → 复核页评语非本地模板固定文案，且 console 无报错

### AC-2：照片手写识别参与主观题判分
- **Type**：`rule`
- **Given**：学生给一道主观题上传了手写照片（文本框为空或有补充），并配置了可用的视觉模型
- **When**：提交作业触发主观题判分
- **Then**：图片被发送给视觉模型识别手写内容，结合题目要点给出分数与评语，评语中提及识别到的作答要点
- **Pass Condition**：附照片的主观题提交后，`aiReviews` 中该题评语包含识别内容或"已识别手写"类表述，且 `usedVision === true`（或等价标记）
- **Evidence**：浏览器自测——配置视觉模型 → 简答附图（用生成的测试图片）→ 提交 → 复核页评语引用了图片内容

### AC-3：无视觉模型 / 未配置时优雅降级
- **Type**：`rule`
- **Given**：未配置视觉模型，或视觉模型调用失败
- **When**：提交附照片的主观题
- **Then**：回退本地评分（有文本按文本评；无文本仅照片给保底分），评语提示"AI 未识别图片，请教师查阅"，不抛错、不丢数据
- **Pass Condition**：清除视觉模型配置后提交附照片简答，提交成功、有分数、console 无未捕获异常
- **Evidence**：浏览器自测 + console 为空

### AC-4：课堂问答作答页倒计时显示
- **Type**：`rule`
- **Given**：学生进入一道 `mode === 'quiz'` 的课堂问答作答
- **When**：作答页渲染
- **Then**：页面顶部 / 答题卡区显示倒计时（分:秒），每秒递减
- **Pass Condition**：作答页存在倒计时元素，10 秒内数字发生变化
- **Evidence**：浏览器自测——进入课堂问答 → 截图 / 读取 DOM 含倒计时，等待 3 秒数字变小

### AC-5：倒计时归零自动提交并判分
- **Type**：`rule`
- **Given**：学生在课堂问答作答中，倒计时走到 0
- **When**：倒计时归零
- **Then**：自动调用提交判分流程（已答的题判分，未答的题计 0 分），跳转到结果页，提示"时间到，已自动提交"
- **Pass Condition**：将 `duration` 临时设为极小值（如 5 秒），进入作答后等待归零，页面自动出现结果与得分
- **Evidence**：浏览器自测——设置短时 → 等待自动提交 → 结果页出现

### AC-6：刷新页面倒计时不重置
- **Type**：`rule`
- **Given**：学生已开始一道限时课堂问答（记录了开始时间）
- **When**：刷新浏览器或重新进入该作答页
- **Then**：倒计时基于原始开始时间继续，不重新计时
- **Pass Condition**：开始作答后刷新，剩余时间 ≈ 刷新前剩余时间（误差 ≤ 刷新耗时）
- **Evidence**：浏览器自测——记录刷新前后剩余秒数

### AC-7：学生端有自主练习入口
- **Type**：`rule`
- **Given**：学生已登录并加入班级
- **When**：查看学生端底部 / 侧栏导航
- **Then**：存在"自主练习"入口，点击进入自主练习页
- **Pass Condition**：导航含"自主练习"，点击后路由为 `#/student/practice-self`（或等价），页面渲染无报错
- **Evidence**：浏览器自测——登录学生 → 看到并点击入口 → 页面正常

### AC-8：内置真题库可按知识点 / 难度抽题组卷
- **Type**：`rule`
- **Given**：学生在自主练习页
- **When**：选择课程、知识点、难度，点击"开始练习"
- **Then**：从内置真题库抽取匹配题目组成一份练习卷，进入作答
- **Pass Condition**：高数与大物各至少有 6 道真题（单选 + 简答混合），覆盖 ≥ 4 个知识点、含基础 / 提高两档难度；抽题结果非空
- **Evidence**：代码检查题库数据 + 浏览器自测抽题成功

### AC-9：自主练习作答后自动判分并展示解析
- **Type**：`rule`
- **Given**：学生完成一份自主练习卷并提交
- **When**：提交
- **Then**：单选即时判分、简答本地 / 大模型判分，结果页展示得分、每题对错、标准答案与解析，练习写入历史
- **Pass Condition**：提交后出现得分与解析，错题本 / 练习历史可查到该次记录
- **Evidence**：浏览器自测——做一份练习 → 提交 → 结果页含解析，历史列表新增一条

### AC-10：大模型可在自主练习中现场出题
- **Type**：`rule`
- **Given**：学生在自主练习页，已配置可用文本模型
- **When**：选择知识点 + 难度，点击"AI 出题"
- **Then**：调用大模型生成一道新题（题干 / 选项 / 答案 / 解析），加入当前练习卷可立即作答；未配置模型时提示并禁用
- **Pass Condition**：配置模型后点击 AI 出题，当前卷新增一道题且含题干与答案；未配置时按钮提示"请先配置模型"
- **Evidence**：浏览器自测——配置模型 → AI 出题 → 新题出现；清除配置 → 按钮禁用 / 提示

### AC-11：旧浏览器数据自动升级不报错
- **Type**：`rule`
- **Given**：浏览器中存在 `version === 4` 的旧数据
- **When**：加载新版本页面
- **Then**：自动重建为 `version === 5` 的种子数据（含真题库、duration 等），页面可正常使用，console 无报错
- **Pass Condition**：`loadDb` 对 `version !== 5` 的数据走 `buildSeed()`；新数据含真题库与作业 `duration`
- **Evidence**：浏览器自测——置 `version=4` 旧数据 → 刷新 → 数据重建、功能正常

### AC-12：AI 判分与识别结果质量
- **Type**：`rubric`
- **Dimension**：判分评语的相关性与可解释性
- **Scale**：1-5
- **Anchors**：1 = 评语与题目无关 / 纯模板；3 = 评语基本相关但无分步；5 = 评语结合题目要点与教材页码、分步指出对错，照片识别内容被引用
- **Pass Threshold**：>= 4
- **Evidence**：提交 1 道简答（附照片）后人工阅读评语，评估相关性

### AC-13：自主练习交互体验
- **Type**：`rubric`
- **Dimension**：抽题 / 作答 / 结果流程的顺畅度
- **Scale**：1-5
- **Anchors**：1 = 入口难找 / 流程断裂；3 = 能用但步骤冗余；5 = 入口清晰、组卷作答判分看解析一气呵成
- **Pass Threshold**：>= 4
- **Evidence**：走通一次完整自主练习流程的主观评估

### AC-14：降级与离线可用性
- **Type**：`rubric`
- **Dimension**：未配置模型时的功能完整性与提示友好度
- **Scale**：1-5
- **Anchors**：1 = 未配置时功能报错 / 不可用；3 = 功能可用但提示缺失；5 = 全部功能离线可用，降级处有清晰提示且不影响主流程
- **Pass Threshold**：>= 4
- **Evidence**：清除所有模型配置后走通：自主练习抽题作答判分、课堂问答倒计时自动交卷、简答本地评分
