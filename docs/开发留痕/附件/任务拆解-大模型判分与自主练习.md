# 知课AI — 大模型判分 / 照片识别 / 限时 / 自主练习 — 实施计划

## Task 1：数据层升级与真题库（version 4→5）
- **Status**：`pending`
- **Priority**：high
- **Depends On**：None
- **Description**：
  - `data.js` / `data-math.js` / `data-physics.js`：`seed.version` 由 4 升 5；新增 `examQuestions` 真题库（高数、大物各 ≥6 道，单选 + 简答混合，覆盖 ≥4 个知识点，含 `difficulty: 基础/提高`、`source: '真题'`）。
  - 给 `mode === 'quiz'` 的作业加 `duration`（分钟，默认 10）。
  - `store.js` `loadDb`：版本校验改为 `=== 5`，旧数据自动 `buildSeed()`；新字段（`duration`、`examQuestions`、`practiceRecords`）对旧数据做兜底。
- **Acceptance Criteria Addressed**：AC-8、AC-11
- **Test Requirements**：
  - `rule` TR-1.1：`seed.version === 5` 且 `loadDb` 对 `version !== 5` 的数据走 `buildSeed()`；证据 = 代码 + 浏览器置旧数据后刷新重建。
  - `rule` TR-1.2：高数与大物真题库各 ≥6 题，覆盖 ≥4 个知识点，含基础 / 提高两档；证据 = 代码数据检查。
  - `rule` TR-1.3：每条 quiz 作业含数值型 `duration`；证据 = 代码检查。
- **Notes**：真题基于现有课件知识点编制，复用题目对象结构 `{id,type,stem,options,answer,score,knowledgeId,keywords,hints,diagnosis,source,difficulty}`。

## Task 2：真实大模型参与主观题判分（文本）
- **Status**：`pending`
- **Priority**：high
- **Depends On**：Task 1
- **Description**：
  - `actions.js` 新增异步 `gradeShortAnswerLLM(q, text, images)`：构造系统提示（题目 + 标准答案要点 + 关联教材页码 + 满分），要求模型返回严格 JSON `{"score":number,"comment":string,"steps":[...]}`；解析失败 / 网络失败 / 未配置时回退 `mockAi.gradeShortAnswer`。
  - `submitAssignment` / `submitRedo` 中主观题判分改为 `await gradeShortAnswerLLM(...)`，结果写入 `aiReviews`，附加 `usedLLM: true/false` 标记。
  - 学生结果页 / 教师复核页在评语处展示"AI 生成 · 仅供参考"标记（当 `usedLLM`）。
- **Acceptance Criteria Addressed**：AC-1、AC-12
- **Test Requirements**：
  - `rule` TR-2.1：配置可用文本模型后提交含主观题的作业，该题 `aiReviews` 含 `usedLLM === true` 且分数来自模型；证据 = 浏览器自测 + 读取 `db`。
  - `rule` TR-2.2：未配置模型 / 模型返回非 JSON 时回退本地评分，提交成功、console 无未捕获异常；证据 = 浏览器自测 + console 为空。
  - `rubric` TR-2.3：评语相关性（AC-12）；scale 1-5；锚点 1=无关/纯模板，3=基本相关无分步，5=结合要点+页码+分步；阈值 ≥4；证据 = 人工阅读提交后的评语。

## Task 3：视觉模型 adapter 与照片手写识别判分
- **Status**：`pending`
- **Priority**：high
- **Depends On**：Task 2
- **Description**：
  - `store.js`：扩展 LLM 配置，新增 `visionModel` / `visionBaseUrl`（可与文本模型相同）；`callLLM` 支持 `images`（dataURL 数组）参数——OpenAI 兼容厂商把 content 改为数组含 `{type:"image_url", image_url:{url}}`；dashscope 走其多模态 payload 结构（独立 adapter）。
  - `actions.js` `gradeShortAnswerLLM`：当 `images.length > 0` 时，优先用视觉模型识别手写 → 将识别文本并入作答 → 再判分；评语引用识别到的要点，附加 `usedVision: true`；无视觉模型或失败时降级（有文本按文本、无文本给保底分）并提示。
- **Acceptance Criteria Addressed**：AC-2、AC-3、AC-14
- **Test Requirements**：
  - `rule` TR-3.1：配置视觉模型后给简答附测试图片并提交，该题 `aiReviews` 评语含识别内容或"已识别手写"表述、`usedVision === true`；证据 = 浏览器自测。
  - `rule` TR-3.2：清除视觉模型配置后提交附照片简答，回退本地评分 + 提示，不丢数据、不报错；证据 = 浏览器自测 + console 为空。
  - `rule` TR-3.3：`callLLM` 对 OpenAI 兼容与 dashscope 分别构造 payload，不混用；证据 = 代码检查。
- **Notes**：遵循"多供应商独立 adapter"经验，禁止同一 payload 硬套所有厂商。

- **Depends On**：Task 1
