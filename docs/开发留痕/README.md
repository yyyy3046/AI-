# 开发过程留痕

对应「创熠」AI 聚变黑客松选手手册 06 节第 5 项「开发过程留痕」。

## 内容

| 文件 | 说明 |
| --- | --- |
| `开发过程记录.pdf` | **提交用**：按时间线还原「需求 → 设计 → 开发 → 验证 → 提交」的完整链路，含关键功能与提交对应关系、验证记录、附件与截图清单 |
| `开发过程记录.html` | PDF 源文件（可直接浏览器打开、可再导出 PDF） |
| `截图/` | 真实开发过程截图（应用界面演进） |
| `附件/` | TRAE 中形成的真实需求规格、任务拆解与开发计划文档 |

## 数据来源

- TRAE 会话记录与项目记忆（按会话整理的需求 / 动作 / 结果）
- TRAE 中的需求规格、任务拆解、开发计划文档（`附件/`）
- Git 提交历史（共 19 次提交，可在仓库逐条核查）
- 开发与线上部署过程中的真实界面截图（`截图/`）

## 尚需补充（赛制要求「能看出在 TRAE 里对话、改代码」）

1. 建议再补 1—2 张 TRAE 会话面板截图（含需求对话与代码改动）；
2. 逐字提示词原文可在 TRAE 会话面板导出完整对话，与本记录合并后重新导出 PDF。

## 重新导出 PDF

用 Microsoft Edge 无头模式打印即可：

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" `
  --headless=new --disable-gpu --no-pdf-header-footer `
  --print-to-pdf="开发过程记录.pdf" `
  "file:///<本目录绝对路径>/开发过程记录.html"
```
